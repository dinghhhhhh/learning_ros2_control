欢迎使用 transmission_interface 文档
=======================================================

``transmission_interface`` 包含用于表示机械传动机构的数据结构、在 actuator 与 joint 空间之间传播数值的方法，以及支持这些功能的工具。

有关 ros2_control 框架的更多信息，请参阅 `control.ros.org <https://control.ros.org/>`__。
